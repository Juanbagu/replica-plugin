# Replica

Claude Code plugin with the 11 skills of the Replica pack (v12) by victorcorralsocial. They guide building your own version of an app, step by step:

1. `/replica-recon` – map screens, flows, data model and features
2. `/replica-architect` – stack, schema and API
3. `/replica-design` – design tokens and components (with a contrast checker)
4. `/replica-build` – build screen by screen
5. `/replica-backend` – auth, database, payments, email
6. `/replica-test` – test plan and end-to-end tests
7. `/replica-diff` – feature parity and screenshot diff
8. `/replica-entrepreneur` – what real users complain about, positioning
9. `/replica-brand` – your own name, palette, voice, leftover sweep
10. `/replica-launch` – landing page, pricing, store listing
11. `/replica-deploy` – go live on your own domain

## Install

```
/plugin marketplace add <owner>/<repo>
/plugin install replica@replica-marketplace
```
